## 仍需明确的技术边界

- `failed_logins` 是历史兼容字段名，当前统计的是源 IP 发往 21/22/3389 目的端口的包命中数，不是真实失败登录次数。若要改字段名，需同步训练数据、模型输入、API、前端和规则，不应只改解析器。
- `num_unique_ports` 是整个 PCAP 范围内的源 IP 级统计；同一个源 IP 的多条连接可能得到相同值。
- `src_bytes` / `dst_bytes` 按首次观察到的包方向区分，不保证对应固定客户端/服务器方向；字节长度取自 IP payload，包含 TCP/UDP 头，不是纯应用层数据。
- 当前解析器只处理 TCP/UDP；`PROTO_MAP` 虽预留 ICMP 编码，ICMP 包实际仍会被跳过。
- TCP 会话切分仍是轻量级逻辑。抓包丢包、缺少 FIN/RST、会话中途开始等都可能导致边界不准；UDP 还没有基于空闲超时切分。
